Solo-Backup-Modus, Notizen zu vergangenen Spielständen und eine Konfliktwarnung, die auch ohne Server funktioniert.

## Neu

- 🎒 **Solo-Backup-Modus** — eine neue Onboarding-Option, um CoopSync ganz ohne zweiten Spieler zu nutzen: vollständiges Speicherstand-Backup und Versionsverlauf, ganz allein. Eignet sich zugleich hervorragend, um zwischen dem eigenen PC und Laptop zu synchronisieren. Für bestehende Host/Join-Setups ändert sich nichts.
- 📝 **Notizen zu vergangenen Spielständen** — hänge nachträglich eine Notiz an jeden Push in der Spielhistorie an (z. B. "Welt beschädigt, diese Version nicht herunterladen"), plus ein "Als beschädigt markieren"-Flag, das eine Warnung direkt auf der Spielkarte zeigt, solange genau diese Version in der Cloud liegt.
- 🔒 **Warnung vor einem möglichen Speicherkonflikt** — beim Starten eines Spiels wird jetzt eine kleine Sperrdatei im gemeinsamen Repository geprüft, die warnt, wenn jemand anderes das Spiel kürzlich ebenfalls gestartet hat — funktioniert auch ohne Verbindung zum Signalisierungsserver, als Rückfallebene zur bestehenden "Freund spielt gerade"-Meldung.
- 🛡️ **SECURITY.md und ein klarerer Login-Schritt** — eine Sicherheitsrichtlinie zum Melden von Schwachstellen hinzugefügt, plus eine "Was genau erlaubt das?"-Erklärung direkt beim Login-Schritt, bevor du dein GitHub-Konto verbindest.
