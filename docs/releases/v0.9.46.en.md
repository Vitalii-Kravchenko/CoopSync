The app now finds out about a new release the moment it ships, and two more update-related buttons can't be double-clicked anymore.

## New

- 🔔 **The app hears about a new release right away** — until now, a running instance only rechecked for updates every 6h on its own, so a fresh release could sit unnoticed in the tray for hours. The signaling server now watches GitHub releases and nudges every connected client the moment one goes live, spread out over a few minutes so nobody's app hits GitHub at the exact same second.

## Fixed

- 🖱️ **"Restart to install" could be clicked more than once** — the "Download" button already had a fast-double-click guard, but the button that actually restarts and installs didn't, on any of its 3 surfaces (Settings, the Games tab banner, the toast). Fixed the same way.
- ✖️ **The × on toast notifications had no hover feedback** — the cursor changed on hover, but the button itself never visibly lit up. Turned out an inline style was silently blocking the CSS rule meant to do it.
