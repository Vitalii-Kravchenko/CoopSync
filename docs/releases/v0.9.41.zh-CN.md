在线状态显示、按游戏设置的"仅自己/共享"同步范围,以及围绕这两者的一批修复。

## 新增

- 👥 **查看队友是否在线** — 头像上的圆点(现在移到右上角)加上旁边的状态标签。现在一次 GitHub 登录就涵盖所有功能,不再需要单独为在线状态登录。
- 🔒 **按游戏设置同步范围** — "仅自己" / "与好友共享"开关现在适用于任何游戏,不再局限于额外文件夹。即使主仓库仍与好友共享,也能让某个游戏的存档保持私密。
- 队友删除共享的游戏或文件夹时,你现在会看到一个"恢复"选项,而不是本地副本被悄悄清空。
- 删除额外文件夹现在也会真正删除共享仓库里的内容,而不只是去掉本地引用、让空间在暗地里继续被占用。
- 存档位置和同步范围现在合并到一张更紧凑的卡片里,并重新设计了"仅自己"/"共享"切换按钮。

## 修复

- 卸载 CoopSync 不再清空所有本地设置(自定义存档路径、按游戏设置的同步范围、语言、头像)——现在只有手动移除游戏,或自己删除应用的数据文件夹,才会这样。
- 把共享的自定义游戏切换为"仅自己"后,不会再连带取消队友那边的共享。
- 在游戏本身没有实际变化的情况下切换同步范围,不再增加(或减少)版本号;在"仅自己"模式下取得的真实进度,切回"共享"后现在能正确出现在共享历史记录里。
- 修复了一处可能导致额外文件夹被重复生成的竞态问题。
- 快速或连续点击按钮时,按钮上的文字不再被选中。
- 修复了"仅自己"/"共享"切换按钮的加载动画短暂使按钮变形的视觉问题。
