Die App erfährt jetzt sofort von einer neuen Version, und zwei weitere Update-Buttons lassen sich nicht mehr doppelt anklicken.

## Neu

- 🔔 **Die App erfährt sofort von einer neuen Version** — bisher hat eine laufende Instanz nur alle 6h von selbst erneut nach Updates gesucht, sodass eine frische Version stundenlang unbemerkt im Tray liegen konnte. Der Signaling-Server beobachtet jetzt GitHub-Releases und stößt jeden verbundenen Client an, sobald eine neue Version live geht — verteilt über ein paar Minuten, damit nicht alle im selben Moment auf GitHub zugreifen.

## Behoben

- 🖱️ **„Neu starten zum Installieren" ließ sich mehrfach anklicken** — der „Herunterladen"-Button hatte bereits einen Schutz gegen schnelles Doppelklicken, der Button, der tatsächlich neu startet und installiert, aber nicht — auf keiner seiner 3 Oberflächen (Einstellungen, Banner im Spiele-Tab, Toast). Genauso behoben.
- ✖️ **Das × bei Toast-Benachrichtigungen zeigte beim Hover keine Reaktion** — der Cursor änderte sich beim Hover, aber der Button selbst leuchtete nie sichtbar auf. Ein Inline-Style hat die dafür zuständige CSS-Regel stillschweigend blockiert.
