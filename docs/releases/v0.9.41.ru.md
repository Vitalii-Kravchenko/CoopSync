Онлайн-статус друга, область синхронизации «только я / общее» теперь для любой игры, и серия исправлений вокруг обоих.

## Новое

- 👥 **Видно, когда напарник онлайн** — значок на его аватарке (теперь в верхнем правом углу) и статус рядом. Один логин GitHub теперь покрывает всё — отдельный вход для присутствия больше не нужен.
- 🔒 **Область синхронизации для каждой игры** — переключатель «Только я» / «Общее с другом» теперь работает для ЛЮБОЙ игры, а не только для дополнительных папок. Можно держать сейвы конкретной игры приватными, даже если основной репозиторий общий с другом.
- Когда напарник удаляет общую игру или папку, теперь появляется опция «Восстановить» вместо тихого удаления локальной копии.
- Удаление дополнительной папки теперь действительно убирает её содержимое и из общего репозитория, а не только локальную ссылку, которая тихо продолжала занимать место.
- Расположение сейвов и область синхронизации теперь в одной объединённой, более компактной карточке, с переработанным переключателем «Только я»/«Общее».

## Исправлено

- Деинсталляция CoopSync больше не стирает все локальные настройки (пути к сейвам, область синхронизации для каждой игры, язык, аватар) — теперь это происходит только при удалении игры вручную или самостоятельном стирании папки данных приложения.
- Переключение общей кастомной игры на «только для меня» больше не отключает её от общего доступа у напарника.
- Переключение области синхронизации без реальных изменений в игре больше не меняет номер версии; реальный прогресс, сделанный в режиме «только я», теперь корректно попадает в общую историю после возврата на «общее».
- Исправлено состояние гонки, из-за которого дополнительная папка могла материализоваться дважды.
- Текст на кнопках больше не выделяется при быстром или повторном клике.
- Исправлен визуальный баг, из-за которого индикатор загрузки на переключателе «Только я»/«Общее» на миг деформировал кнопку.
