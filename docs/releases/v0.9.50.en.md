Private per-device settings sync, an experimental-game confirmation loop, and screenshots in bug reports.

## New

- 🔒 **Personal settings stay personal** — some games keep per-player settings (keybinds, graphics options) in the very same folder as the shared world save. Those now sync privately between your own devices instead of being ignored or ending up visible to your co-op partner. Subnautica 2 is the first game using this.
- 🧪 **Experimental badge + confirmation loop** — a game whose save-file split isn't fully confirmed yet shows an "experimental" badge, and after a real sync you'll occasionally see a quick "did this work for you?" prompt. Three separate "yes" answers count toward promoting the game to fully verified. "Found a problem" opens Support with the game already filled in.
- 📎 **Screenshots in bug reports** — attach up to 3 screenshots when reporting a bug. The bug-report game picker now also searches your own already-synced games instead of the whole Steam catalog.
