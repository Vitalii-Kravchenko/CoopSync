A game can now have more than one save folder — and each one can be shared with your co-op partner or kept just for you.

## New

- 📁 **Extra save folders per game** — sync a second (or third) folder independently from a game's main save, e.g. character saves kept separate from world saves. Add one from a game's detail screen: give it a name, point it at a folder, and choose whether it's **shared with your co-op partner** (synced the same way as the main save) or **just for you** — a personal folder still backs up to the cloud with its own version history, just into a private space under your own account that your partner never sees.
- ↩️ **Restoring an old version now restores extra folders too** — reverting a game's main save to an earlier point automatically restores each extra folder to its own matching state from that same moment, so a world and its characters always come back together.
- 🛡️ **Guardrails for the new folders** — CoopSync now blocks a folder (or a game) whose save path would overlap with another one already being synced, and blocks two games or two folders on the same game from sharing a name — both used to be able to quietly corrupt each other's data.

## Fixed

- Sync versions for a game's main save and its extra folders now stay consistent with each other instead of drifting apart, and a save made while you're still playing (not just on quitting) keeps everything — world and extras — in step.
- A background check that used to occasionally delete a game or folder by mistake, based on a single ambiguous reading, is gone — it converges safely now.
- The "Refresh" button on the Games tab no longer flashes the whole list away and back — it now updates quietly in place.
- Manual sync toasts now fade out and pause briefly before the next one appears, instead of snapping straight to it.

Thanks for the thorough testing today — several of these were found and nailed down through real back-and-forth, not guesswork.
