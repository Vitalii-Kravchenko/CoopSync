Warns about OneDrive/Dropbox conflicts, and never loses a save to a sync conflict again.

## New

- ☁️ **Warn if a save folder is already synced by OneDrive/Dropbox** — some games' save folders end up inside a OneDrive- or Dropbox-synced folder without you ever choosing that (Windows enrolls "Documents" into OneDrive by default on plenty of PCs). CoopSync now detects the overlap and warns on the Games screen — both writing to the same files at once can corrupt a save, especially through OneDrive's "Files On-Demand" placeholders. Toggle in Settings → General, on by default.
- 🌿 **Never lose a save to a sync conflict again** — if the cloud moved ahead while you were playing (your friend pushed first), your session used to just get silently skipped with no way to get it back. It's now preserved to its own conflict branch instead — nothing is ever overwritten, and nothing is ever lost. The conflict notification gets a new "Save a copy" button that pulls it out to a plain folder in your Documents to review or merge by hand.
