O app agora fica sabendo de uma nova versão assim que ela sai, e mais dois botões relacionados a atualização não podem mais ser clicados duas vezes.

## Novo

- 🔔 **O app fica sabendo de uma nova versão na hora** — até agora, uma instância em execução só verificava atualizações a cada 6h por conta própria, então uma versão nova podia ficar horas sem ser notada na bandeja. O servidor de sinalização agora observa os releases no GitHub e avisa cada cliente conectado assim que um novo sai — espalhado ao longo de alguns minutos para que ninguém acesse o GitHub no mesmo instante.

## Corrigido

- 🖱️ **"Reiniciar para instalar" podia ser clicado mais de uma vez** — o botão "Baixar" já tinha proteção contra clique duplo rápido, mas o botão que realmente reinicia e instala não tinha, em nenhuma das 3 superfícies (Configurações, o banner na aba Jogos, o aviso). Corrigido da mesma forma.
- ✖️ **O × dos avisos não reagia ao passar o mouse** — o cursor mudava, mas o botão em si nunca acendia visivelmente. Um estilo inline estava silenciosamente bloqueando a regra CSS que deveria fazer isso.
