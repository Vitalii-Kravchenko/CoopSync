单人备份模式、为过往存档添加备注，以及一个即使没有服务器也能生效的冲突警告。

## 新功能

- 🎒 **单人备份模式** — 引导流程中新增的一个选项，让你完全不需要第二位玩家也能使用 CoopSync：独自享有完整的存档备份和版本历史。同时也是在自己的台式机和笔记本之间同步的简便方式。已有的房主/加入设置不受任何影响。
- 📝 **为过往存档添加备注** — 事后为游戏历史中的任意一次推送添加备注（例如"存档损坏了，不要下载这个版本"），还有一个"标记为损坏"的开关，只要该版本仍在云端，就会直接在游戏卡片上显示警告。
- 🔒 **可能存在存档冲突的警告** — 启动游戏时现在会检查共享仓库里的一个小型锁文件，如果最近有其他人也启动过这款游戏就会发出警告——即使没有连接信令服务器也能生效，作为现有"好友正在游戏"提示的补充保障。
- 🛡️ **新增 SECURITY.md，登录步骤更清晰** — 新增了用于报告漏洞的安全政策，并在连接 GitHub 账户之前的登录步骤里，直接展示"这到底允许什么"的说明。
