Онлайн-статус друга, перемикач «тільки я / спільно» тепер для будь-якої гри, і серія виправлень навколо обох.

## Нове

- 👥 **Видно, коли твій напарник онлайн** — значок на його аватарці (тепер у верхньому правому куті) і статус поруч. Один логін GitHub тепер покриває все — окремого входу для присутності більше не треба.
- 🔒 **Область синхронізації для кожної гри** — перемикач «Тільки я» / «Спільно з другом» тепер працює для БУДЬ-ЯКОЇ гри, не тільки для додаткових папок. Можна тримати сейви конкретної гри приватними, навіть якщо основний репозиторій спільний з другом.
- Коли напарник видаляє спільну гру чи папку, у тебе тепер з'являється опція «Відновити» замість тихого видалення локальної копії.
- Видалення додаткової папки тепер справді прибирає її вміст і зі спільного репозиторію, а не лише локальне посилання, яке тихо продовжувало займати місце.
- Розташування сейвів і область синхронізації тепер в одній об'єднаній, компактнішій картці, з переробленим перемикачем «Тільки я»/«Спільно».

## Виправлено

- Деінсталяція CoopSync більше не стирає всі локальні налаштування (шляхи до сейвів, область синхронізації для кожної гри, мову, аватар) — тепер це відбувається тільки якщо видалити гру вручну або самому стерти папку даних застосунку.
- Перемикання спільної кастомної гри на «тільки для мене» більше не забирає її зі спільного простору у напарника.
- Перемикання області синхронізації без реальних змін у грі більше не змінює номер версії; реальний прогрес, зроблений в режимі «тільки я», тепер коректно потрапляє в спільну історію синхронізації після повернення на «спільно».
- Виправлено стан гонки, через який додаткова папка могла матеріалізуватися двічі.
- Текст на кнопках більше не виділяється при швидкому або повторному кліку.
- Виправлено візуальний глюк, коли крутилка завантаження на перемикачі «Тільки я»/«Спільно» на мить деформувала кнопку.
