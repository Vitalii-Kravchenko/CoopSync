Переработанная карточка дополнительных папок сейвов, плюс серия исправлений вокруг кастомных игр.

## Новое

- 🗂️ **Дополнительные папки сейвов — новый вид** — карточка папки теперь показывает только название, значок владельца, статус синхронизации и кнопки Загрузить/Скачать. Путь к папке, переключатель «Только я»/«Общая», исключение файлов и удаление папки теперь скрыты за настройками — это выбирается один раз и редко меняется потом. Карточки стоят по две в ряд на широком окне и сворачиваются в один ряд на всю ширину, когда для двух не хватает места.

## Исправлено

- Индикатор шагов в «Добавить кастомную игру» больше не выглядит так, будто соединительная линия и второй шаг сместились вправо.
- Крестик закрытия модалки и блок «добавить обложку» теперь имеют тот же стиль наведения, что и весь остальной интерфейс (и настоящий курсор-указатель).
- Список исключённых файлов теперь обновляется сам при изменении пути к сейвам игры, а не продолжает показывать файлы из старой папки.
- Кнопки «Только я»/«Общая с другом» для дополнительной папки теперь в правильном порядке и по размеру текста, а не растянуты каждая на половину карточки.
- Значок «Кастомная игра» рядом со статусом синхронизации теперь выровнен по центру относительно него, а не сидит выше.
- Несколько строк на экране деталей кастомной игры (заголовок, путь к сейвам, опасная зона) теперь переносятся на свою строку вместо сжатия на узком окне.
- Карточки «Автосинк .exe» и «Исключить файлы» на экране деталей кастомной игры теперь одинаковой высоты и реально расходятся на отдельные строки, когда окну не хватает ширины для двух рядом.
