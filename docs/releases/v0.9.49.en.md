Solo backup mode, notes on past saves, and a save-conflict warning that works even without the server.

## New

- 🎒 **Solo backup mode** — a new onboarding option for using CoopSync without a second player at all: full save backup and version history, on your own. Doubles as an easy way to sync between your own PC and laptop. No change for existing host/join setups.
- 📝 **Notes on past saves** — attach a note to any push in a game's history after the fact (e.g. "world got corrupted, don't download this one"), plus a "mark as broken" flag that shows a warning right on the game's card while that version is still the one in the cloud.
- 🔒 **Warn about a possible save conflict** — launching a game now checks a small lock file in the shared repo and warns if someone else launched it recently too — works even when the signaling server isn't connected, as a backup for the existing "friend is playing" notice.
- 🛡️ **SECURITY.md, and a clearer login step** — added a security policy for reporting vulnerabilities, plus a "what exactly does this allow?" disclosure right on the login step, before you connect your GitHub account.
